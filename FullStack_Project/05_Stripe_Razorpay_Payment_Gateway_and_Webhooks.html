Unsigned Vulnerable Webhook vs Production Idempotent Handler

❌ Vulnerable Webhook (Unsigned & Non-Idempotent)

public function handle(Request $request) {
    // 1. Accepts any unverified POST payload from the internet!
    $data = $request->all();
    
    // 2. Marks order paid without checking if already processed!
    $order = Order::find($data['order_id']);
    $order->status = 'paid';
    $order->save();
    
    // 3. Duplicate gateway retries will credit vendor wallet 5 times!
    $order->vendor->increment('balance', $order->total);
}

✅ Production-Hardened Webhook (Signed & Idempotent)

public function handle(Request $request) {
    // 1. Verify cryptographic signature
    $event = Webhook::constructEvent(
        $request->getContent(), 
        $request->header('Stripe-Signature'), 
        config('services.stripe.webhook_secret')
    );

    // 2. Idempotency guard: Return 200 if already processed
    if (WebhookCall::where('external_event_id', $event->id)->where('status', 'processed')->exists()) {
        return response('Already Processed', 200);
    }

    // 3. Atomic execution with row-level locks
    DB::transaction(fn () => $this->settleOrder($event));
    return response('Handled', 200);
}
