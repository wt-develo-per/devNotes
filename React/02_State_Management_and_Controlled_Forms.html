State Immutability: Objects & Arrays in React

React relies on reference changes (Object.is). Mutating state in-place will NEVER trigger a re-render:

Operation ❌ Deadly Mutation (No Re-render) ✅ Safe Immutable Update
Object Property user.name = 'Pankaj'; setUser(user); setUser(prev => ({ ...prev, name: 'Pankaj' }));
Add to Array items.push(newItem); setItems(items); setItems(prev => [...prev, newItem]);
Delete from Array items.splice(idx, 1); setItems(items); setItems(prev => prev.filter(i => i.id !== id));
Update Array Item items[0].status = 'done'; setItems(prev => prev.map(i => i.id === id ? { ...i, status: 'done' } : i));
Laravel FormRequest 422 Response Structure & Mapping

Laravel validation errors are returned as keyed arrays: { "errors": { "field": ["Message 1"] } }:

Laravel FormRequest JSON: 
{
  "message": "The given data was invalid.",
  "errors": {
    "email": [
      "The email has already been taken."
    ],
    "password": [
      "The password must be at least 8 characters."
    ]
  }
}

Debounced Search Against Laravel Database

Stop firing 10 queries on 10 keystrokes. Wait 400ms after user stops typing: 

const debounceRef = useRef(null);

const handleSearch = (e) => {
    const val = e.target.value;
    setQuery(val);

    // Cancel previously queued API call:
    if (debounceRef.current) clearTimeout(debounceRef.current);

    if (!val.trim()) {
        setResults([]);
        return;
    }

    // Schedule API call after 400ms idle:
    debounceRef.current = setTimeout(async () => {
        setIsSearching(true);
        const res = await axios.get(`/api/products?search=${encodeURIComponent(val)}`);
        setResults(res.data.data);
        setIsSearching(false);
    }, 400);
};
Production-Ready Controlled Form Component

Complete clean architecture template with loading spinner, validation errors, and disabled submit state: 

export default function UserForm() {
    const [form, setForm] = useState({ name: '', email: '', role: 'user' });
    const [errors, setErrors] = useState({});
    const [submitting, setSubmitting] = useState(false);

    const handleChange = (e) => {
        const { name, value } = e.target;
        setForm(prev => ({ ...prev, [name]: value }));
        // Clean error as user types:
        if (errors[name]) setErrors(prev => ({ ...prev, [name]: null }));
    };

    const handleSubmit = async (e) => {
        e.preventDefault();
        setSubmitting(true);
        try {
            await axios.post('/api/users', form);
            alert('Saved successfully!');
        } catch (err) {
            if (err.response?.status === 422) setErrors(err.response.data.errors);
        } finally {
            setSubmitting(false);
        }
    };

    return (
        <form onSubmit={handleSubmit}>
            <input name="name" value={form.name} onChange={handleChange} />
            {errors.name && <p className="error">{errors.name[0]}</p>}
            <button disabled={submitting}>{submitting ? 'Saving...' : 'Save'}</button>
        </form>
    );
}
