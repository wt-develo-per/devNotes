Inertia.js Server-Side Rendering (SSR) Master Guide

Deliver 100% crawlable pre-rendered HTML for Googlebot and social media previews:

# 1. Install Inertia Server:
npm install @inertiajs/server

# 2. Build Client & SSR assets:
npm run build

# 3. Supervisor Daemon (/etc/supervisor/conf.d/ssr.conf):
[program:inertia-ssr]
command=php /var/www/myapp/artisan inertia:start-ssr
autostart=true
autorestart=true
user=www-data
Component Testing with Vitest & Testing Library

Fast, declarative testing matching your Pest / PHPUnit standards: 

import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { test, expect } from 'vitest';
import Counter from './Counter';

test('increments counter on button click', async () => {
    render(<Counter initialCount={0} />);
    
    const button = screen.getByRole('button', { name: /increment/i });
    await userEvent.click(button);

    expect(screen.getByText('Count: 1')).toBeInTheDocument();
});
XSS Sanitization with DOMPurify

Never render raw HTML from database without cryptographic sanitization: 

import DOMPurify from 'dompurify';

export function ProductDescription({ htmlContent }) {
    // Strips malicious <script>, onload=, and <iframe> attacks:
    const cleanHtml = DOMPurify.sanitize(htmlContent);

    return (
        <div 
            className="prose max-w-none" 
            dangerouslySetInnerHTML={{ __html: cleanHtml }} 
        />
    );
}
Top 15 Full-Stack Laravel + React Interview Matrix

Essential technical punchlines for senior full-stack interview rounds:

Topic Question Winning Technical Punchline
Architecture Inertia vs Decoupled SPA Inertia is a monolith adapter keeping session cookies and routes in Laravel without REST API or client router overhead.
Security Why not store tokens in localStorage? localStorage is 100% accessible via XSS scripts; Sanctum HttpOnly cookies are physically blocked from JS access.
Performance useMemo vs useCallback useMemo caches computed values (arrays/numbers); useCallback caches function instance pointers for React.memo.
State Server vs Client State Server state (orders/users) belongs in Inertia props; Client state (cart/modals) belongs in Zustand.
SEO How does Inertia SSR work? Node process pre-renders React tree to HTML string via ReactDOMServer; Laravel injects into Blade for crawlers.
Forms How does useForm handle files? Automatically detects File/Blob instances in data and converts HTTP request payload to multipart/form-data.
