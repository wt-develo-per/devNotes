The 3 Dependency Array Modes — Behavior Matrix

Dependency array governs when and how often the effect executes:

Syntax When Does It Run? Typical Laravel Use Case Danger Level
useEffect(fn)
(No array)		 After every single render Logging DOM mutations or measuring element size ⚠ Critical: Calling setState inside triggers infinite loop!
useEffect(fn, [])
(Empty array)		 Once on mount (initial paint) Initial Laravel API fetch (/api/user), setting up global event listener Safe (Runs only once)
useEffect(fn, [id, page])
(With dependencies)		 On mount + whenever dependencies change Fetching paginated orders or user profile when route parameter changes Controlled (Re-runs only on value change)
Zero Memory Leaks: Axios with AbortController

Cancel pending network sockets immediately if user navigates away before API responds: 

useEffect(() => {
    // 1. Create native browser AbortController:
    const controller = new AbortController();

    async function loadData() {
        try {
            const res = await axios.get(`/api/invoices/${invoiceId}`, {
                signal: controller.signal // Pass signal to Axios
            });
            setInvoice(res.data);
        } catch (err) {
            // Ignore cancel errors (user intentionally navigated away):
            if (!axios.isCancel(err)) {
                setError(err.message);
            }
        }
    }

    loadData();

    // 2. Cleanup function runs automatically on unmount:
    return () => {
        controller.abort(); // Drops the TCP socket! No unmounted state warning!
    };
}, [invoiceId]);
Top 3 Infinite Loop Traps in React for Laravel Devs

Never do these three patterns in production components:

❌ Trap 1: Setting State Without Dep Array 
useEffect(() => {
    // Render -> Effect -> setState -> Render -> Effect...
    setCount(count + 1); // INFINITE LOOP!
});
❌ Trap 2: Object in Dependencies 
// { page: 1 } is a NEW object reference on every render!
const options = { page: 1 };
useEffect(() => {
    fetchData();
}, [options]); // INFINITE LOOP!
✅ How to Fix: Use primitive values in dependencies (e.g. [options.page] instead of [options]), or memoize objects with useMemo.
useRef vs useState Decision Matrix

When should you use useRef instead of useState?

Requirement Recommended Hook Why?
Updating UI / Text on screen useState React needs to re-render to update the DOM tree.
Auto-focusing an input box on modal open useRef Direct imperative DOM element reference (inputRef.current.focus()).
Storing setTimeout / setInterval timer ID useRef Changing timer ID should never cause screen re-render.
Tracking previous prop or render count useRef Mutates silently in background without triggering new render cycles.
