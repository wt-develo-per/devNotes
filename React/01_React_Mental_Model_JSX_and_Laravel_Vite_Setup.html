Interactive: Blade to React Transformation Pipeline

Traditional server-rendered Blade template se modern declarative React component tak ka 6-step refactoring workflow:

Blade Directives vs React JSX Syntax Translation Matrix

Agar aap Blade likhte hain, to React mein same functionality likhne ka cheat-sheet:

Concept Laravel Blade Syntax React JSX Equivalent
Variable Interpolation {{ $user->name }} {user.name}
Raw HTML Output {!! $htmlContent !!} dangerouslySetInnerHTML={{ __html: htmlContent }}
Conditionals (If / Else) @if($isAdmin) ... @else ... @endif {isAdmin ? <AdminBadge /> : <UserBadge />}
Short-circuit Check @isset($user) <div>...</div> @endisset {user && <div>...</div>}
Looping / Lists @foreach($items as $item) ... @endforeach {items.map(item => <Item key={item.id} {...item} />)}
CSS Classes class="btn {{ $active ? 'active' : '' }}" className={`btn ${active ? 'active' : ''}`}
Slots / Children {{ $slot }} or <x-slot:title> {children} prop or custom named props
Laravel 10/11 Vite + React Configuration Blueprint

Step-by-step production configuration files for Vite + React Fast Refresh:

vite.config.js: 
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';
import react from '@vitejs/plugin-react';

export default defineConfig({
    plugins: [
        laravel({
            input: ['resources/css/app.css', 'resources/js/app.jsx'],
            refresh: true,
        }),
        react(), // Required for React JSX HMR
    ],
});
welcome.blade.php: 
<head>
    <meta charset="utf-8">
    <title>Laravel React</title>

    {{-- 1. MUST put @viteReactRefresh FIRST --}}
    @viteReactRefresh
    {{-- 2. Include JS entrypoint --}}
    @vite(['resources/css/app.css', 'resources/js/app.jsx'])
</head>
<body>
    <div id="app" data-page="{{ json_encode($pageData) }}"></div>
</body>

The "Key Prop" Trap: Index vs Stable Unique ID

Why array index as key breaks dynamic list updates:

Scenario Using key={index} Using key={item.id}
Item Added to Top Every existing item's index shifts (0 becomes 1). React re-renders EVERY row in the list! React detects old IDs are untouched, mounts ONLY the new item. Zero unnecessary DOM updates.
Item Deleted Next item takes deleted item's index. Uncontrolled input values/checkboxes stay on the wrong row! React cleanly unmounts the exact DOM node associated with the deleted ID.
List Re-sorted React mutates content inside same DOM nodes instead of moving elements efficiently. React re-orders existing DOM nodes with minimal painting.
