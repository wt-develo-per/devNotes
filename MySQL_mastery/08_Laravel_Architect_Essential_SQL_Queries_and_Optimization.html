Interactive: Laravel Performance Debugging Pipeline

Production high latency (2.5s) se sub-50ms API response tak pahunchne ka 6-step engineering protocol:

Production Query Profiling & Threshold Alarms

Telescope local par theek hai, lekin production environment mein lightweight non-intrusive logging zaroori hai.

Tool / Hook Where to Place Recommended Threshold
DB::whenQueryingForLongerThan() AppServiceProvider::boot() 200ms to 500ms (Production Slack / Sentry alert)
DB::listen() Local / Staging environments only Log queries > 100ms with full URL and bindings
MySQL slow_query_log /etc/mysql/my.cnf long_query_time = 0.5 (500ms) with log-queries-not-using-indexes
mysqldumpslow Production CLI mysqldumpslow -s at -t 10 /var/log/mysql/slow.log
Pagination Shootout — Deep Page Latency Comparison

Table of 5,000,000 orders — Latency comparison as users/crawlers navigate deeper:

Method Page 1 (Limit 20) Page 500 (Offset 10k) Page 50,000 (Offset 1M) Total Count Query?
paginate() 12ms 420ms 4,800ms ❌ Yes (Heavy COUNT(*))
simplePaginate() 3ms 380ms 4,100ms ❌ No
cursorPaginate() 2ms ✅ 2.1ms ✅ 2.3ms ✅ No (Constant Time O(1))
Pro Tip: Mobile apps aur infinite scroll feeds mein hamesha cursorPaginate() use karein. Regular admin tables jahan page 1-10 se aage koi nahi jaata wahan paginate() chal sakta hai.
Large Dataset Processing — Memory & Mutation Matrix

100,000 records export ya update karte waqt memory crash aur skipped records se bachein:

Method Memory Profile Safe for Mutating Rows? Underlying Mechanism
all() / get() High (~150MB+) ❌ Yes Loads all rows and hydrates all models at once
chunk(1000) Medium (~20MB) NO! (Skipped records trap) ❌ LIMIT 1000 OFFSET n (OFFSET shifts when rows mutate)
chunkById(1000) Medium (~20MB) YES ✅ WHERE id > last_id ORDER BY id ASC LIMIT 1000
cursor() Ultra Low (~4MB) ✅ Yes PHP Generator streaming rows one-by-one via PDO unbuffered
lazy(1000) Low (~15MB) ✅ Yes Laravel LazyCollection chunks streamed lazily into collection pipelines
Redis Cache Tags & Laravel Octane Gotchas

MySQL 8.0 query cache removal ke baad application-level caching aur persistent worker state management:

Pattern / Environment Best Practice Deadly Trap to Avoid
Cache Tags Cache::tags(['products', 'cat-4'])->remember() Redis without tags requires complex wildcard key deletion scripts
Observer Invalidation Model saved() and deleted() hooks mein tags flush karein Stale pricing/stock showing to customers after admin updates
Laravel Octane (State) Request lifecycle events mein state clean karein Uncommitted transactions leaking into the next HTTP request
Connection Dropouts config/database.php mein PDO reconnect options on rakhein "MySQL server has gone away" error on idle workers
