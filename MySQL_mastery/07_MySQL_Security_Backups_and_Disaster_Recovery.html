Interactive: Complex Query Engineering Pipeline

Raw client requirements se lekar production-ready, injection-safe SQL & Laravel implementation tak ka 6-step engineering flow:

Recursive Common Table Expressions (CTE) — Hierarchy & Networks

Category trees, nested comments, org charts, aur referral chains ko bina PHP loops ke 1 single query mein traverse karne ka gold standard.

Component Role in Query Example in Hierarchy
Anchor Member Recursion ka starting point define karta hai SELECT id, name, parent_id, 1 as depth FROM categories WHERE id = :rootId
UNION ALL Anchor aur recursive results ko concatenate karta hai Must use UNION ALL (MySQL does not support UNION DISTINCT in recursive CTEs)
Recursive Member Pichle result set ke output ko join karke agle level rows nikalta hai SELECT c.id, c.name, c.parent_id, cp.depth + 1 FROM categories c JOIN category_path cp ON c.id = cp.parent_id
Termination Condition Cycle detection ya maximum depth guard WHERE cp.depth < 10 (infinite loop se server bachaane ke liye) 
-- Full Recursive Category Breadcrumb in Laravel:
$breadcrumbs = DB::select("
    WITH RECURSIVE category_tree AS (
        SELECT id, name, parent_id, 1 AS depth, CAST(name AS CHAR(1000)) AS path
        FROM categories WHERE id = ?
        UNION ALL
        SELECT c.id, c.name, c.parent_id, ct.depth + 1, CONCAT(c.name, ' > ', ct.path)
        FROM categories c
        INNER JOIN category_tree ct ON c.id = ct.parent_id
        WHERE ct.depth < 10
    )
    SELECT path FROM category_tree ORDER BY depth DESC LIMIT 1;
", [$categoryId]);
Window Functions — MySQL 8.0+ Analytical Powerhouse

Rows ko aggregate karke calculation karta hai bina unhe collapse kiye — Har row apni identity retain karti hai.

Window Function Ties Handling Typical Laravel Use Case
ROW_NUMBER() Unique row number (1, 2, 3, 4) Top 3 products per category, deduplicating records
RANK() Gaps on ties (1, 2, 2, 4) Gaming leaderboards, competition rankings
DENSE_RANK() No gaps on ties (1, 2, 2, 3) Salary tiers, customer VIP loyalty bands
LAG(col, 1) Previous row value Day-over-day revenue delta, user login interval
LEAD(col, 1) Next row value Time spent on page (next_event_time - current_event_time)
SUM(col) OVER(...) Cumulative running sum Customer lifetime spend running balance on invoice PDF
Conditional Aggregation — Single-Scan Executive Dashboards

Admin dashboards ke 8 metrics ko 8 separate queries mein run karne ke bajaye ek hi disk pass mein fetch karo.

❌ Beginner (6 Queries, 480ms): 
$total    = Order::count();
$paid     = Order::where('status', 'paid')->count();
$failed   = Order::where('status', 'failed')->count();
$rev      = Order::where('status', 'paid')->sum('total');
$refunds  = Order::where('status', 'refunded')->sum('total');
✅ 3-Year Pro (1 Query, 28ms): 
$stats = DB::table('orders')->selectRaw("
    COUNT(*) AS total_orders,
    COUNT(CASE WHEN status='paid' THEN 1 END) AS paid_cnt,
    COUNT(CASE WHEN status='failed' THEN 1 END) AS failed_cnt,
    COALESCE(SUM(CASE WHEN status='paid' THEN total ELSE 0 END), 0) AS rev,
    COALESCE(SUM(CASE WHEN status='refunded' THEN total ELSE 0 END), 0) AS refunds
")->first();
Raw SQL Security — Vulnerability vs Prevention

Laravel Query Builder ke raw methods mein SQL injection rokne ka definitive guide.

Method Dangerous Pattern Safe Parameterized Pattern
whereRaw() ->whereRaw("email = '$email'") ->whereRaw("email = ?", [$email])
havingRaw() ->havingRaw("SUM(total) > $min") ->havingRaw("SUM(total) > ?", [$min])
orderByRaw() ->orderByRaw($request->sort) Whitelist pattern: ['asc'=>'price ASC'][$sort] ?? 'id DESC'
selectRaw() ->selectRaw("price * $rate as converted") ->selectRaw("price * ? as converted", [$rate])
