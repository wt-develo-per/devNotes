If `folderId` is missing, the request is rejected immediately, and you don't waste AWS bandwidth processing the file upload. ##### Example 10: Centralized Error Translation **Problem:** Your API serves French and English users. You need the Zod error messages to be in different languages. **Solution:** Because all validation happens in ONE Universal Middleware, you can check `req.headers['accept-language']` right inside the middleware, and map the Zod error codes to custom French/English dictionaries before sending the 400 response!
