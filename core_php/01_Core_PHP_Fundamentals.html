Match Expression: Strict Type Comparison (===), Returns a Value, and No Break Statements Needed.

<?php
// ❌ Old Switch (Loose comparison '==' causes nasty type bugs!):
$statusCode = '200'; // String

switch ($statusCode) {
    case 200: // Integer 200 == '200' is TRUE in loose comparison!
        $message = 'OK';
        break;
    default:
        $message = 'Unknown';
        break;
}

// ✅ Modern PHP 8+ Match Expression (Strict '===', returns value directly):
$message = match ($statusCode) {
    200      => 'OK (Integer)',
    '200'    => 'OK (Exact String Match)',
    301, 302 => 'Redirect',
    404      => 'Not Found',
    default  => 'Unknown Status',
};

// Match also supports complex boolean pattern expressions:
$age = 22;
$group = match (true) {
    $age < 13 => 'Child',
    $age < 20 => 'Teenager',
    $age >= 20 => 'Adult',
};
?>

Null Coalescing Operators: Eliminate verbose isset() checks cleanly.

<?php
// 1. PHP 5 Era (Verbose Ternary + isset):
$page = isset($_GET['page']) ? $_GET['page'] : 1;

// 2. PHP 7 Null Coalescing Operator (??):
// Checks both isset() AND is not null in one stroke!
$page = $_GET['page'] ?? 1;

// Chained fallback lookup:
$username = $_POST['username'] ?? $_SESSION['username'] ?? 'Guest';

// 3. PHP 7.4+ Null Coalescing Assignment (??=):
// Assigns value ONLY if the variable is null or unset!
$config = [];
$config['timeout'] ??= 30; // Sets 30
$config['timeout'] ??= 60; // Still 30! Doesn't overwrite existing value.
?>

Strict Types & Modern Union Types: Catch bugs at compile time.

<?php
// 🛡️ Always place at the VERY TOP of the file (Line 1):
declare(strict_types=1);

// PHP 8+ Union Types & Nullable Types:
function calculateDiscount(int|float $price, ?float $discountRate = null): int|float
{
    if ($discountRate === null) {
        return $price;
    }

    return $price - ($price * $discountRate);
}

// Valid calls:
calculateDiscount(100, 0.2); // 80.0
calculateDiscount(45.50);    // 45.50

// ❌ Throws TypeError in strict_types mode:
// calculateDiscount("100", "0.2"); // Fatal error: Uncaught TypeError!
?>
