Interactive PHP OOP Architecture & Advanced Patterns

Click through the core paradigms of enterprise PHP OOP to see how modern encapsulation, inheritance, LSB, and generators operate under the hood:

Property Overloading: The underlying mechanism behind Laravel Eloquent dynamic attributes.

<?php
class DynamicModel
{
    protected array $attributes = [];

    // Invoked automatically when reading an inaccessible or non-existent property
    public function __get(string $name): mixed
    {
        return $this->attributes[$name] ?? null;
    }

    // Invoked automatically when writing to an inaccessible property
    public function __set(string $name, mixed $value): void
    {
        // Mutate or sanitize before storing!
        $this->attributes[$name] = $value;
    }

    public function __isset(string $name): bool
    {
        return isset($this->attributes[$name]);
    }
}

$user = new DynamicModel();
$user->email = 'admin@corp.com'; // Calls __set('email', 'admin@corp.com')
echo $user->email;               // Calls __get('email')
?>

Method Overloading: The foundation of Laravel Facades and Query Builder forwarding.

<?php
class ServiceProxy
{
    protected RealWorker $worker;

    public function __construct() {
        $this->worker = new RealWorker();
    }

    // Dynamic instance method forwarding:
    public function __call(string $method, array $arguments): mixed
    {
        echo "Intercepted call to dynamic method: {$method}()\n";
        return $this->worker->{$method}(...$arguments);
    }

    // Dynamic static method forwarding (Laravel Facade pattern!):
    public static function __callStatic(string $method, array $arguments): mixed
    {
        $instance = static::resolveInstance();
        return $instance->{$method}(...$arguments);
    }
}
?>

Invokable Objects & String Casting: Clean Action Classes & Value Objects.

<?php
// Invokable Class: Can be called directly as a function!
final class CalculateInvoiceTax
{
    public function __invoke(float $amount, float $taxRate = 0.18): float
    {
        return $amount * (1 + $taxRate);
    }
}

$taxCalculator = new CalculateInvoiceTax();
$total = $taxCalculator(1000.0); // Directly invokes __invoke() -> returns 1180.0

// Value Object with __toString:
final class Money
{
    public function __construct(public int $cents, public string $currency = 'INR') {}

    public function __toString(): string
    {
        return sprintf('%s %.2f', $this->currency, $this->cents / 100);
    }
}

$price = new Money(4999);
echo "Final Price: " . $price; // Auto-casts: "Final Price: INR 49.99"
?>
