Vulnerability: Attacker passes {"is_admin": true, "balance": 99999} in POST payload.

<?php
// ❌ VULNERABLE: Direct $request->all() into Model::create()
public function store(Request $request) {
    // Hacker payload: {"name": "Hacker", "email": "h@k.com", "is_admin": true}
    $user = User::create($request->all()); // Hacker becomes SUPERADMIN!
}

// ✅ 1. SECURE: Use $request->validated() or $request->safe()
public function store(RegisterUserRequest $request) {
    $user = User::create($request->validated()); // Only whitelisted fields pass!
}

// ✅ 2. ENTERPRISE ENFORCEMENT: Enable Strict Mode in AppServiceProvider
// app/Providers/AppServiceProvider.php
public function boot(): void {
    // Development me unfillable field aate hi turant Exception throw karega!
    \Illuminate\Database\Eloquent\Model::shouldBeStrict(! $this->app->isProduction());
}
?>

CSRF Protection: How CSRF tokens work and how to configure webhook exemptions.

<?php
// 1. In Blade Forms (Generates hidden input _token):
// <form method="POST" action="/transfer">
//     @csrf
//     ...
// </form>

// 2. In Single Page Apps / Mobile (Axios & Fetch):
// Laravel sets an unencrypted XSRF-TOKEN cookie on every response.
// Axios automatically reads this cookie and sends it in the X-XSRF-TOKEN header!

// 3. Excluding Webhooks from CSRF (Laravel 10 vs Laravel 11/12/13)
// Laravel 10: app/Http/Middleware/VerifyCsrfToken.php -> protected $except = ['stripe/*'];
// Laravel 11, 12, 13: bootstrap/app.php:
return Application::configure(basePath: dirname(__DIR__))
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->validateCsrfTokens(except: [
            'stripe/webhook',
            'api/v1/payments/razorpay-callback',
            'github/webhook',
        ]);
    })->create();
?>

SQL Injection in Raw Methods: Eloquent does NOT escape raw strings automatically!

<?php
// ❌ VULNERABLE: Direct string concatenation inside whereRaw() or orderByRaw()
$category = $request->query('category'); // Value: "electronics' OR 1=1 -- "
$products = Product::whereRaw("category = '$category'")->get(); // SQL INJECTION!

$sortBy = $request->query('sort'); // Value: "price; DROP TABLE users;--"
$products = Product::orderByRaw("$sortBy ASC")->get(); // SQL INJECTION!

// ✅ SAFE 1: Pass bindings array to whereRaw()
$products = Product::whereRaw('category = ?', [$category])->get();

// ✅ SAFE 2: Use whitelisted column matching for dynamic orderBy
$allowedSorts = ['price', 'created_at', 'rating'];
$column = in_array($request->query('sort'), $allowedSorts, true) ? $request->query('sort') : 'created_at';
$products = Product::orderBy($column, 'desc')->get();
?>
