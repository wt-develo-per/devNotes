Resources & Data Transformation

Database models ko directly API response mein bhejna security risk aur tight coupling create karta hai. API Resources use karke apne data structure ko frontend ke liye customize karna seekhein.

Intermediate

1. The Problem with returning Models

Junior developers aksar seedha Eloquent model return kar dete hain: return User::find($id);. Ye ek bohot badi galti hai kyunki:

  • Aap accidentally sensitive data (like password, remember_token, ya internal IDs) leak kar sakte hain (agar $hidden properly configured na ho).
  • Agar database column ka naam change hota hai, toh API contract break ho jata hai jisse frontend apps (React/Vue/Mobile) crash ho sakti hain.
  • Dates aur booleans inconsistent format mein render ho sakte hain.

🛡️ The Solution

Data ko client tak bhejne se pehle ek "Transformation Layer" se pass karein. Laravel mein ise API Resources (Eloquent Resources) kaha jata hai.

Mastery

2. Creating API Resources

Terminal command: php artisan make:resource UserResource

Is file ke andar hum define karenge ki ek "User" API mein kaisa dikhna chahiye, irrespective of uski database reality kya hai.

app/Http/Resources/UserResource.php
namespace App\Http\Resources;

use Illuminate\Http\Request;
use Illuminate\Http\Resources\Json\JsonResource;

class UserResource extends JsonResource
{
    public function toArray(Request $request): array
    {
        // Contract defined: Even if DB column 'first_name' changes to 'f_name' later,
        // the API will ALWAYS output 'first_name' keeping frontend happy.
        return [
            'id'         => $this->id,
            'full_name'  => $this->first_name . ' ' . $this->last_name,
            'email'      => $this->email,
            'is_active'  => (bool) $this->status, // Type casting explicitly
            'joined_at'  => $this->created_at->format('Y-m-d H:i:s'),
            
            // Conditionally include fields only if admin is requesting
            'admin_notes' => $this->when($request->user()->isAdmin(), $this->notes),
        ];
    }
}

3. Conditional Relationships (The N+1 Killer)

Senior level par aapko dhyan rakhna hota hai performance ka. Agar aap relation ko resource mein load kar dein 'posts' => PostResource::collection($this->posts) aur controller se usay eager load (with('posts')) karna bhool jayein, toh N+1 query problem aa jayegi.

Is-se bachne ke liye Laravel ka whenLoaded use karein. Ye relation tabhi include karega jab wo specifically load ki gayi ho.

UserResource.php (Extended)
public function toArray(Request $request): array
{
    return [
        'id'        => $this->id,
        'full_name' => $this->first_name,
        
        // 'posts' key will only appear in JSON if User::with('posts') was called
        // Prevents accidental N+1 database queries!
        'posts'     => PostResource::collection($this->whenLoaded('posts')),
        
        // Same for single relations
        'profile'   => new ProfileResource($this->whenLoaded('profile')),
    ];
}
Mastery Implementation

4. Resource Collections & Pagination

Jab aap ek se zyada models return kar rahe hon (like an index page with pagination), toh aap UserResource::collection($users) use karte hain. Lekin agar aapko overall pagination metadata customize karni hai, toh aapko ResourceCollection banani padegi.

Command: php artisan make:resource UserCollection

app/Http/Resources/UserCollection.php
namespace App\Http\Resources;

use Illuminate\Http\Request;
use Illuminate\Http\Resources\Json\ResourceCollection;

class UserCollection extends ResourceCollection
{
    // Explicitly state which resource class to map to
    public $collects = UserResource::class;

    public function toArray(Request $request): array
    {
        return [
            'data' => $this->collection,
            
            // Adding custom metadata specifically for lists
            'meta' => [
                'total_active_users' => $this->collection->where('status', true)->count(),
                'api_version' => 'v1'
            ],
        ];
    }
}

In Controller:

public function index()
{
    // Eager load posts to satisfy 'whenLoaded' in UserResource
    $users = User::with('posts')->paginate(15);
    
    // Use the custom collection which uses UserResource internally
    return new UserCollection($users);
}
