Top 30 DSA Interview Questions

Practical Arrays, Strings, & Hash Maps for Startups (Hinglish Explanations)

Q1. What is Big O Notation?
"Big O batata hai ki jab data (n) bohot badh jayega (jaise 10 se 10 million), toh aapka code kitna time zyada lega (Time Complexity) aur kitni RAM khayega (Space Complexity). Startups me O(N^2) loops likhne walo ko turant reject kar dete hain."
Q2. Reverse a String (Without inbuilt methods).
"Sabse common! Hum ek 'Two Pointer' approach use karte hain. Ek pointer string ke start (left = 0) par, aur ek end (right = str.length-1) par rakhte hain. Dono characters ko swap karte hain aur left ko aage, right ko piche late hain jab tak wo cross na ho jayein. Time: O(N)."
Q3. Find the Max and Min element in an Array.
"Array ko sort mat karna! Wo O(N log N) time lega. Seedha ek single loop lagao (O(N)). 2 variables rakho `max` aur `min`. Har number ko check karo, agar wo max se bada hai toh max update kardo, agar min se chota hai toh min update kardo."
Q4. Check if a String is a Palindrome.
"Palindrome matlab ulta-seedha ek saman (Jaise 'racecar'). Isme bhi 'Two Pointer' lagao. Left index ko Right index se compare karo. Agar kahi bhi match nahi hua, return `false`. Agar loop khatam ho gaya toh `true`. Time: O(N/2) => O(N)."
Q5. Two Sum Problem. (Find 2 numbers that add up to Target)
"Do nested loops (loop ke andar loop) lagane se O(N^2) aayega. Ise solve karne ka best tarika **Hash Map (Object/Map)** hai! Har number par jao, check karo ki `Target - CurrentNumber` Map me pehle se hai kya? Agar hai, toh answer mil gaya! Agar nahi, toh current number ko Map me save kardo. Time: O(N)."
Q6. Remove duplicates from an Array.
"Sabse easy tarika JS me `new Set(array)` use karna hai kyunki Set duplicates allow nahi karta. Agar bina extra space (In-place) karna ho sorted array me, toh Two Pointers use karo. Ek pointer unique numbers ko track karega, dusra aage badhega."
Q7. Find the Missing Number in an Array of 1 to N.
"Maths zindabad! 1 se N tak sabka sum nikalne ka formula hai `N * (N + 1) / 2`. Isme se given array ke saare elements ka sum minus kar do. Jo number bachega, wahi missing number hai! Time: O(N), Space: O(1)."
Q8. Best Time to Buy and Sell Stock.
"Aapko array me lowest price par kharidna hai aur highest par bechna hai. Ek variable rakho `minPrice` (infinity) aur ek `maxProfit` (0). Loop me, agar aaj ka price minPrice se chota hai, toh usko update kardo. Nahi toh, profit check karo (`todayPrice - minPrice`) aur maxProfit update kardo."
Q9. Valid Parentheses. (e.g. "{[()]}" is valid)
"Isme **Stack** (Array with push/pop) use hota hai. Jab bhi opening bracket aaye `(`, `{`, `[`, usko stack me Push kardo. Jab bhi closing bracket aaye `)`, toh Stack me Pop karo aur check karo ki kya wo same type ka hai? End me agar Stack khali hai toh valid hai!"
Q10. Move all Zeroes to the end of the Array.
"Array ke non-zero numbers ko left me shift karte jao. Ek variable `insertPos = 0` rakho. Jab bhi koi non-zero number mile, usko `arr[insertPos]` par dal do aur `insertPos++` kardo. Loop ke baad, bache hue saare indexes me 0 bhar do."
Q11. Find the Majority Element (Appears more than N/2 times).
"Boyer-Moore Voting Algorithm! Ek 'candidate' variable banao aur 'count' ko 0 rakho. Array par iterate karo. Agar count 0 hai, toh current number ko candidate bana do. Agar current number candidate se match karta hai toh `count++`, varna `count--`. Jo end me candidate bachega wahi answer hai."
Q12. What is the Sliding Window Technique?
"Agar array me lagatar (contiguous) elements ka subarray dhundhna ho (Jaise: max sum of 3 consecutive elements). Toh baar-baar loop lagane ke bajaye, hum ek 3 size ka 'Window' banate hain. Jab window aage khisakti hai, toh left element minus karte hain aur right naya element plus karte hain. O(N)."
Q13. Longest Substring Without Repeating Characters.
"Isme Sliding Window + Set use hota hai. Ek Left pointer aur ek Right pointer. Right pointer ko aage badhao aur character ko Set me dalo. Agar character pehle se Set me hai (repeating), toh Left pointer ko aage badhao aur us character ko Set se nikalo jab tak duplicate hat na jaye."
Q14. Merge Intervals (e.g. [1,3], [2,6] becomes [1,6]).
"Pehle saare intervals ko unke Start time ke hisaab se Sort kardo. Ek empty result array banao. Iterate karo, agar pichle interval ka End aage wale interval ke Start se bada ya barabar hai, toh dono ko merge kardo (`Math.max(end1, end2)`). Warna naye interval ko result me push kardo."
Q15. Reverse a Linked List.
"Linked List me Pointers update karne hote hain. 3 variables chahiye: `prev` (null), `curr` (head), aur `next` (null). Jab tak `curr` null na ho jaye, `next = curr.next` save karo, phir `curr.next = prev` kardo (ulta link). Phir `prev = curr` aur `curr = next` karke aage badh jao."
Q16. Detect a Cycle in a Linked List.
"Floyd's Tortoise and Hare algorithm (Kachhua aur Khargosh)! Ek slow pointer rakho jo 1 step chale, ek fast pointer rakho jo 2 steps chale. Agar linked list me gol chakkar (cycle) hai, toh Fast wala ghoom kar Slow wale se zarur takrayega (`slow === fast`)."
Q17. Find the Middle of a Linked List.
"Isme bhi Kachhua aur Khargosh lagta hai. Fast pointer 2 steps, slow 1 step. Jab fast wala end par pahuch jayega (`fast.next === null`), toh slow wala automatically EXACTLY middle me hoga! Ye trick array ki tarah length naapne se bacha leti hai."
Q18. Merge Two Sorted Arrays.
"Dono arrays par ek-ek pointer lagao (i aur j). Jo element chota ho usko ek naye array me push kardo, aur us pointer ko aage badha do. End me jo bhi array bach jaye, uske saare elements ko copy kardo."
Q19. Check if two strings are Anagrams. (e.g. "listen" and "silent")
"Ek tarika: dono ko split, sort aur join karke check karlo (slow). Best tarika: Ek Hash Map me string A ke characters ka frequency (count) store karo. Phir string B par loop lagao aur map me count kam (minus) karte jao. Agar map me sab 0 bache, toh wo Anagram hain."
Q20. Find the First Non-Repeating Character in a String.
"String par pehle ek loop lagakar Hash Map me sabhi characters ka count save karlo. Phir string par ek dusra loop lagao, aur map me check karo jiska bhi count exactly 1 hai, usko return kardo. Time O(N)."
Q21. Binary Search Algorithm.
"Array SORTED hona zaroori hai. Ek `left = 0` aur `right = len-1` pointer lo. Middle element check karo. Agar target middle se chota hai, toh `right = mid-1` kardo (left side dhoondho). Agar bada hai toh `left = mid+1` (right side dhoondho). Isse Time Complexity O(log N) ho jati hai (bohot fast)."
Q22. What is a Hash Collision and how do you handle it?
"Jab 2 alag keys (jaise 'John' aur 'Doe') ka Hash function same index number (e.g. index 5) generate kar de memory me. Isko handle karne ke 2 tarike hain: 1. Chaining (Us index par ek array/linked-list bana do). 2. Open Addressing (Agar index 5 full hai, toh agla khali space dhundo, jaise index 6)."
Q23. Implement a Queue using Stacks.
"Queue FIFO (First-In-First-Out) hota hai, Stack LIFO hota hai. Isko banane ke liye 2 Stacks chahiye (`stack1` aur `stack2`). Push hamesha `stack1` me karo. Pop karte waqt, `stack1` ka saara data `stack2` me palat do (ulta ho jayega) aur phir `stack2` se pop kardo."
Q24. Maximum Subarray Sum (Kadane's Algorithm).
"Negative aur Positive numbers wale array me lagatar elements ka maximum sum dhundhna. Ek `currentSum` aur `maxSum` rakho. Har number ko `currentSum` me add karo. Agar `currentSum` Negative ho jaye, toh usko 0 kar do (kyunki negative number pichle sum ko barbaad kar dega). Har step me `maxSum` update karte raho."
Q25. Maximum Depth (Height) of a Binary Tree.
"Recursion ka magic! Base case: Agar root null hai, toh return 0. Nahi toh `leftDepth = maxDepth(root.left)` aur `rightDepth = maxDepth(root.right)` nikalo. Phir un dono me se jo bada (max) ho, usme 1 plus karke return kardo (`Math.max(left, right) + 1`)."
Q26. Invert a Binary Tree.
"Ye wohi question hai jiska answer nahi aane par Homebrew ke founder ko Google ne reject kar diya tha! Recursively ek node ke Left aur Right child ko Aapas me Swap kar do (`temp = root.left; root.left = root.right; root.right = temp;`), aur phir wahi kaam bachon (children) ke liye repeat kardo."
Q27. Difference between BFS and DFS.
"DFS (Depth First Search) matlab pehle puri gehrai tak jao (1 branch complete karo) phir wapas aao. Isme Recursion (Stack) use hota hai. BFS (Breadth First Search) matlab level-by-level jao. Pehle saare padosi (neighbors) explore karo. Isme Queue data structure use hota hai."
Q28. Climb Stairs (Fibonacci sequence DP).
"Aap 1 ya 2 steps le sakte ho. Nth sidi par pahuchne ke kitne tarike hain? Ye actually Fibonacci series hai! Current step tak aane ke tarike = (n-1 step ke tarike) + (n-2 step ke tarike). Ise hum Memoization (Array me results store karke) solve karte hain taaki O(N) me run ho."
Q29. Container With Most Water.
"Two Pointer Approach. Ek pointer left se, ek right se. Area = `Math.min(height[left], height[right]) * distance`. Max area update karo. Jo bhi pillar chhota ho (left ya right), us pointer ko aage/peeche badhao kyunki wahi bottleneck ban raha hai."
Q30. Product of Array Except Self (Without Division).
"Aap total array ko multiply karke division (/) operator use nahi kar sakte! Ise bina uske O(N) me solve karne ke liye hum Prefix and Postfix multiplications use karte hain. Ek pass left se right karte hain (left walon ka product), aur dusra pass right se left karte hain."
