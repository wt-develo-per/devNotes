Multimodal AI, Vision OCR & Audio Workflows in Laravel

Text chat se aage badhein: GPT-4o Vision & Claude 3.5 Sonnet se messy bills, handwritten receipts aur identity cards se structured JSON extract karein. Master karein KYC Fraud Detection, OpenAI Whisper audio transcription for CRM meeting notes, aur AWS S3 pre-signed secure image streaming!

👁️ Beyond Text: Why Traditional OCR is Dead
Kyun Tesseract aur RegEx scraping fail ho jaate hain aur Vision LLMs enterprise automation ko dominate kar rahe hain.

Pichle 10 saalon se developers invoice aur receipt parsing ke liye Tesseract OCR ya AWS Textract use karte the. Phir uske baad 500 lines ka fragile Regular Expressions (RegEx) code likhte the taaki "Total Amount", "Tax", aur "Date" dhund sakein.

❌ The Traditional OCR Nightmare

- Spatial Blindness: Tesseract text ko left-to-right stream padhta hai. Complex multi-column tables mein column headers aur values mix ho jaati hain.
- Real-World Failures: Crumpled receipts, mobile camera ke shadows, tilted photos par accuracy 40% se neeche gir jaati hai.
- Vendor Variations: Har company ka invoice format alag hota hai (kisi mein "Total", kisi mein "Net Payable", kisi mein "Balance Due"). Har format ke liye alag RegEx maintain karna padta tha.

✅ The Vision LLM Revolution (GPT-4o / Claude 3.5)

- Human-Like Visual Intelligence: Model poori image ka spatial layout samajhta hai — tables, borders, handwritten signatures, company stamps aur checkboxes.
- Zero RegEx Required: Model ko direct instruction milti hai: "Extract table items, subtotal, and tax into this JSON schema". 99% first-shot accuracy!
- Multilingual & Handwritten: Hindi, English, Arabic ya doctor ki handwriting bhi effortlessly parse ho jaati hai.

🎙️ Audio Intelligence: From Voice Notes to Database Records

Multimodal sirf images tak limited nahi hai. OpenAI Whisper audio signals ko ultra-high accuracy text mein transcribe karta hai:

  • Sales Rep Voice Notes: Field agent client meeting ke baad 45-second ka voice note WhatsApp ya app par bolta hai. Whisper use text mein convert karta hai aur LLM automatically CRM fields (Client budget, Next meeting date, Objections) populate kar deta hai.
  • Support Call QA Auditing: Customer support calls ko transcribe karke sentiment score calculate karna aur agent compliance check karna.

2. Vision Token Calculation & Detail Modes

Vision LLMs image ko pixels ke roop mein nahi padhte; woh image ko 512x512 pixel tiles mein slice karte hain:

🔍 Low Detail Mode (detail: 'low')

- Cost: Flat 85 tokens (approx $0.00001 per image).
- Use Case: Quick moderation (checking if image is NSFW, checking if an upload is a photo of an ID card vs a selfie, blurry image detection).

📐 High Detail Mode (detail: 'high')

- Cost: 85 base tokens + 170 tokens per 512x512 tile. Ek standard 1080p receipt = approx 765 tokens ($0.00045).
- Use Case: Dense text, receipt line-items, handwritten signatures, financial tables.

💡 Why gpt-4o-mini is an Unbeatable OCR Engine

Pehle GPT-4-Vision $0.03-$0.05 per page charge karta tha. Aaj GPT-4o-mini wahi receipt extraction sirf $0.0004 (4 paise INR!) mein kar deta hai with 99% accuracy! Enterprise manual data entry team ko hire karne se 1,000x cheaper aur 100x faster!

🧾 Automated Invoice OCR & Database Extraction
Vision model aur Strict JSON Schema ko combine karke bills ko direct Eloquent tables mein persist karna.

Ek high-value feature jo har accounting, billing aur logistics SaaS ko chahiye hota hai woh hai Automated Receipt & Invoice Ingestion. Yahan hum Vision input ko Prism::structured() schema ke saath bind karenge:

1. Defining the Complete Invoice JSON Schema

php app/Ai/Schemas/InvoiceExtractionSchema.php 
namespace App\Ai\Schemas;

use Prism\Prism\Schema\ObjectSchema;
use Prism\Prism\Schema\StringSchema;
use Prism\Prism\Schema\NumberSchema;
use Prism\Prism\Schema\ArraySchema;

class InvoiceExtractionSchema
{
    public static function make(): ObjectSchema
    {
        return new ObjectSchema(
            name: 'invoice_extraction',
            description: 'Extract line items, merchant, tax and totals from invoice photo',
            properties: [
                new StringSchema('merchant_name', 'Company or store name issuing the bill'),
                new StringSchema('invoice_number', 'Invoice, Receipt, or Bill number'),
                new StringSchema('invoice_date', 'Date in YYYY-MM-DD format'),
                new StringSchema('tax_id', 'GSTIN, VAT, or Tax registration number if visible'),
                new StringSchema('currency', 'Currency code (e.g. USD, INR, EUR)'),
                new NumberSchema('subtotal', 'Total before tax'),
                new NumberSchema('tax_amount', 'Tax or GST total amount'),
                new NumberSchema('total_amount', 'Final grand total payable'),
                new ArraySchema(
                    name: 'line_items',
                    description: 'Individual items purchased',
                    items: new ObjectSchema(
                        name: 'item',
                        description: 'Purchased item detail',
                        properties: [
                            new StringSchema('description', 'Item name or service description'),
                            new NumberSchema('quantity', 'Quantity of units purchased'),
                            new NumberSchema('unit_price', 'Price per unit'),
                            new NumberSchema('total', 'Line item total price'),
                        ],
                        required: ['description', 'quantity', 'unit_price', 'total']
                    )
                ),
            ],
            required: ['merchant_name', 'total_amount', 'currency', 'line_items']
        );
    }
}

2. Production InvoiceOcrService with Math Sanity Checks

AI extraction ke baad ek vital backend safety check yeh hai ki kya line items ka sum + tax grand total ke barabar hai? Agar 10 cents ka bhi gap ho, toh use audit review ke liye flag karein:

php app/Services/InvoiceOcrService.php 
namespace App\Services;

use App\Models\Invoice;
use App\Ai\Schemas\InvoiceExtractionSchema;
use Prism\Prism\Facades\Prism;
use Prism\Prism\Enums\Provider;
use Prism\Prism\ValueObjects\Messages\Support\Image;
use Illuminate\Support\Facades\DB;

class InvoiceOcrService
{
    public function parseAndPersist(string $imagePath, int $tenantId): Invoice
    {
        // 1. Execute Multimodal Structured Extraction
        $response = Prism::structured()
            ->using(Provider::OpenAI, 'gpt-4o-mini')
            ->withSchema(InvoiceExtractionSchema::make())
            ->withPrompt([
                'Analyze this uploaded invoice image and extract all visible data with extreme mathematical accuracy.',
                Image::fromPath($imagePath),
            ])
            ->generate();

        $data = $response->structured;

        // 2. Math Consistency Audit
        $calculatedItemsTotal = collect($data['line_items'])->sum('total');
        $tax = (float) ($data['tax_amount'] ?? 0);
        $grandTotal = (float) $data['total_amount'];

        // Discrepancy flag if sum does not match grand total
        $hasMathMismatch = abs(($calculatedItemsTotal + $tax) - $grandTotal) > 0.05;

        // 3. Database Persistence inside Transaction
        return DB::transaction(function () use ($data, $tenantId, $hasMathMismatch) {
            $invoice = Invoice::create([
                'tenant_id'            => $tenantId,
                'merchant_name'        => $data['merchant_name'],
                'invoice_number'       => $data['invoice_number'] ?? 'N/A',
                'invoice_date'         => $data['invoice_date'] ?? now()->toDateString(),
                'tax_id'               => $data['tax_id'] ?? null,
                'currency'             => $data['currency'] ?? 'USD',
                'subtotal'             => $data['subtotal'] ?? 0,
                'tax_amount'           => $data['tax_amount'] ?? 0,
                'total_amount'         => $data['total_amount'],
                'needs_manual_review'  => $hasMathMismatch,
                'status'               => $hasMathMismatch ? 'flagged' : 'verified',
            ]);

            foreach ($data['line_items'] as $item) {
                $invoice->items()->create([
                    'description' => $item['description'],
                    'quantity'    => $item['quantity'],
                    'unit_price'  => $item['unit_price'],
                    'total'       => $item['total'],
                ]);
            }

            return $invoice;
        });
    }
}
🪪 Automated KYC Verification & Document Fraud Detection
FinTech aur Marketplace platforms par Identity Card verification aur screen-photo spoofing defense.

FinTech ya Onboarding portals par users aksar fake IDs, computer screen ki photos (screen spoofing), ya expired documents upload karte hain. Vision LLMs ko hum Anti-Fraud Inspection Engine ke roop mein deploy kar sakte hain.

1. The KYC Inspection Schema & Anti-Fraud Flags

php app/Services/KycVerificationService.php 
namespace App\Services;

use App\Models\User;
use Prism\Prism\Facades\Prism;
use Prism\Prism\Enums\Provider;
use Prism\Prism\ValueObjects\Messages\Support\Image;
use Prism\Prism\Schema\ObjectSchema;
use Prism\Prism\Schema\StringSchema;
use Prism\Prism\Schema\BooleanSchema;

class KycVerificationService
{
    public function verifyIdCard(string $idImagePath, User $user): array
    {
        $kycSchema = new ObjectSchema(
            name: 'kyc_verification_result',
            description: 'Evaluate physical identity card authenticity and extract text',
            properties: [
                new StringSchema('document_type', 'Type of ID', enum: ['passport', 'driving_license', 'national_id', 'unknown']),
                new StringSchema('full_name', 'Full name printed on document'),
                new StringSchema('id_number', 'Document unique identification number'),
                new StringSchema('expiry_date', 'Expiration date in YYYY-MM-DD, or null if lifetime'),
                new BooleanSchema('is_screen_photo_spoof', 'True if photo is taken of a computer/laptop monitor (Moiré lines, pixels)'),
                new BooleanSchema('is_physically_tampered', 'True if fonts are mismatched, cut, or altered digitally'),
                new BooleanSchema('is_clearly_legible', 'True if text and photo are sharp and not blurry'),
            ],
            required: ['document_type', 'full_name', 'id_number', 'is_screen_photo_spoof', 'is_physically_tampered', 'is_clearly_legible']
        );

        $response = Prism::structured()
            ->using(Provider::Anthropic, 'claude-3-5-sonnet-20241022')
            ->withSchema($kycSchema)
            ->withPrompt([
                'Inspect this identity document with extreme forensic scrutiny for onboarding compliance.',
                Image::fromPath($idImagePath),
            ])
            ->generate();

        $data = $response->structured;

        // 2. Name Matching Logic (Fuzzy Levenshtein distance)
        $extractedName = strtolower(trim($data['full_name']));
        $registeredName = strtolower(trim($user->name));
        similar_text($extractedName, $registeredName, $percentMatch);

        $isApproved = ! $data['is_screen_photo_spoof'] 
                   && ! $data['is_physically_tampered'] 
                   && $data['is_clearly_legible']
                   && $percentMatch >= 80.0;

        return [
            'status'        => $isApproved ? 'approved' : 'rejected',
            'extracted'     => $data,
            'name_match_pct'=> round($percentMatch, 1),
            'reasons'       => [
                'spoof'     => $data['is_screen_photo_spoof'],
                'tampered'  => $data['is_physically_tampered'],
                'illegible' => ! $data['is_clearly_legible'],
            ]
        ];
    }
}
🎙️ OpenAI Whisper Audio Transcription & Meeting Tasks
Voice memos, customer care recordings aur sales calls ko automated structured CRM notes mein convert karna.

Audio AI mein OpenAI Whisper industry-standard benchmark hai. Yeh diverse accents, background noise aur multi-lingual speech ko 99% accuracy ke saath transcribe karta hai.

1. WhisperAudioService in Laravel

php app/Services/WhisperAudioService.php 
namespace App\Services;

use Illuminate\Support\Facades\Http;
use Illuminate\Http\Client\RequestException;
use Prism\Prism\Facades\Prism;
use Prism\Prism\Enums\Provider;

class WhisperAudioService
{
    /**
     * Transcribe audio file using OpenAI Whisper API
     */
    public function transcribe(string $audioFilePath): string
    {
        $apiKey = config('prism.providers.openai.api_key');

        $response = Http::withToken($apiKey)
            ->timeout(120)
            ->attach('file', fopen($audioFilePath, 'r'), basename($audioFilePath))
            ->post('https://api.openai.com/v1/audio/transcriptions', [
                'model'           => 'whisper-1',
                'response_format' => 'json',
                'temperature'     => 0.0, // Strict acoustic decoding
            ]);

        if (! $response->successful()) {
            throw new RequestException($response);
        }

        return $response->json('text');
    }

    /**
     * Convert raw audio transcript into actionable CRM Tasks
     */
    public function extractCrmTasks(string $transcript): array
    {
        $response = Prism::text()
            ->using(Provider::OpenAI, 'gpt-4o-mini')
            ->withSystemPrompt('You are an executive assistant. Extract concrete commitments, action items, and follow-up deadlines.')
            ->withPrompt(<<<PROMPT
TRANSCRIPT:
{$transcript}

Please extract:
1. Main discussion summary (max 2 sentences)
2. Action Items (assignee, task, deadline)
3. Client Sentiment (positive/neutral/frustrated)
PROMPT)
            ->generate();

        return [
            'raw_transcript' => $transcript,
            'summary_report' => $response->text,
        ];
    }
}
🔒 AWS S3 Pre-Signed URLs & Image Compression Pipeline
Private bucket security, 5-minute signed token access aur upload compression optimization.

Customer financial records, invoices ya government IDs ko kabhi bhi public S3 bucket (public-read) par host nahi kiya ja sakta. Yeh severe compliance aur GDPR violation hai.

1. Secure Temporary Pre-Signed S3 Access

Laravel S3 driver ke zariye hum ek cryptographically signed temporary URL generate karte hain jo sirf 5 minutes ke liye valid rehta hai:

php Temporary S3 URL Generation 
use Illuminate\Support\Facades\Storage;
use Prism\Prism\ValueObjects\Messages\Support\Image;
use Prism\Prism\Facades\Prism;
use Prism\Prism\Enums\Provider;

// 1. S3 bucket is 100% PRIVATE (Block All Public Access enabled)
$s3Path = "tenants/{$tenantId}/invoices/inv_2026_09.jpg";

// 2. Generate 5-minute pre-signed URL
$temporarySignedUrl = Storage::disk('s3')->temporaryUrl(
    $s3Path,
    now()->addMinutes(5)
);

// 3. Pass signed URL directly to Prism Vision!
$response = Prism::text()
    ->using(Provider::OpenAI, 'gpt-4o-mini')
    ->withPrompt([
        'Extract the invoice total and invoice number.',
        Image::fromUrl($temporarySignedUrl), // Secure temporary fetch!
    ])
    ->generate();

// 5 minutes baad yeh URL completely invalidate ho jayega!

2. Image Pre-Processing & Compression Pipeline

Modern smartphone photos 12MB - 18MB (4000x3000px) hoti hain. Direct LLM ko bhejne par upload slow hoga aur Guzzle timeout error aayega.
Intervention Image se photo ko max 1600px width aur 82% quality par compress karein (15MB drops to 280KB without losing OCR readability):

php app/Services/ImageOptimizerService.php 
namespace App\Services;

use Intervention\Image\Laravel\Facades\Image as InterventionImage;

class ImageOptimizerService
{
    /**
     * Downscale and compress image for optimal Vision LLM processing
     */
    public function optimizeForAi(string $sourcePath, string $destinationPath): string
    {
        $image = InterventionImage::read($sourcePath);

        // Scale down if larger than 1600px (Vision LLM tile limit is 2048px)
        if ($image->width() > 1600) {
            $image->scale(width: 1600);
        }

        // Save as optimized JPEG with 82% quality (perfect OCR clarity)
        $image->toJpeg(quality: 82)->save($destinationPath);

        return $destinationPath;
    }
}

2. Production Gotchas: Multi-Page PDFs & 25MB Audio Limits

⚠️ Multi-Page PDF Invoices

Vision LLMs direct PDF binary accept nahi karte (wo images chahte hain). Agar customer PDF upload karta hai, toh spatie/pdf-to-image ke zariye PDF ke first page ko PNG image mein convert karein, fir Vision model ko pass karein.

⚠️ Whisper 25MB Audio File Limit

OpenAI Whisper API 25MB se badi files reject kar deta hai. 1 ghante ki raw WAV recording 150MB ho sakti hai! Solution: Background worker mein ffmpeg use karke audio ko MP3 (64kbps mono) mein compress karein ya 10-minute segments mein split karein.
